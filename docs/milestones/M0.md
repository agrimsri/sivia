## 1. Goal (Restate)
Establish a reproducible repository skeleton where every later milestone can plug in; CI green on an empty pipeline with rigorous guardrails, data contracts, and automated hardware adaptation.

---

## 2. What Was Built
1. **Repository Layout:** Complete directory hierarchy matching ROADMAP §4 across `configs/`, `src/sivia/`, `scripts/`, `tests/`, `docker/`, and `docs/`.
2. **Packaging & Dependency Groups:** `pyproject.toml` with PEP 621 metadata, `core`, `labeling`, `train`, `serve`, `monitor`, and `dev` dependency specifications.
3. **Makefile Automation:** Standard targets implemented: `setup`, `lint`, `format`, `test`, `label`, `train`, `eval`, `export`, `serve`, `monitor`, `loop`, `demo`, `clean`.
4. **Pre-commit Hooks:** Configuration for Ruff linting, formatting, trailing whitespace, end-of-file, and large file size limits (<= 5 MB).
5. **Hardware Probe:** `scripts/probe_hardware.py` inspecting platform, CPU model/cores, RAM, and NVIDIA GPU/VRAM to auto-generate `configs/compute/auto.yaml`.
6. **SQLite Store & Repository:** Schema `src/sivia/store/schema.sql` implementing Section 5.1 data contracts (samples, labels, runs, models, events) with typed Python interface `SiviaStore` in `src/sivia/store/repository.py`.
7. **Config Loader & Deterministic Seeding:** `sivia.utils.config.load_config` (OmegaConf/Hydra) and `sivia.utils.seed.seed_everything` covering Python, NumPy, PyTorch, and cuDNN.
8. **Kit Specification Validation:** `configs/kits/desk_kit_v1.yaml` with Pydantic v2 validation model `sivia.kit.spec.KitSpec` checking normalized slot geometry and class consistency.
9. **Toy Smoke Test Fixture:** 10 synthetic images with standard COCO annotations (`tests/fixtures/toy/`) for fast smoke testing.
10. **Continuous Integration:** `.github/workflows/ci.yml` running multi-Python linting and unit tests using CPU-optimized PyTorch.
